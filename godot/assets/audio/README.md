Drop web-parity audio files in this folder with these exact names:

- `music_loop.mp3`
- `pellet.mp3`
- `power_pellet.mp3`
- `fruit.mp3`
- `ghost_eaten.mp3`
- `game_over.mp3`
- `low_time_warning.mp3`

`GameAudio.gd` will auto-load these from `res://assets/audio/`.
If files are missing, the game keeps running and logs a warning.
